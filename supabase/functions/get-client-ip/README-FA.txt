تابع get-client-ip — IP عمومی کاربر را فقط از پروژه سوپابیس خودت برمی‌گرداند
============================================================================

این تابع چیست؟
-----------
نسخه ۱.۱.۱۰ برای قانون «یه اینترنت، یه حساب» موقع ثبت‌نام، IP عمومی
گوشی را از این تابع می‌خواند. قبلاً IP از سایت‌های ipify.org و
api.ip.sb گرفته می‌شد؛ حالا هیچ سایت دیگری در کار نیست — فقط پروژه
سوپابیس خودت (vpn5g). ثبت‌نام از قبل هم به سوپابیس نیاز داشت، پس این
تابع نقطه خرابی جدیدی اضافه نمی‌کند.

تابع چه می‌کند؟
--------------
IP را از هدرهایی که سوپابیس موقع دریافت درخواست می‌بیند می‌خواند، به
این ترتیب: اول `x-forwarded-for` (اولین مورد قبل از ویرگول)، بعد
`cf-connecting-ip`، بعد `x-real-ip`. جواب این است:

    {"ip": "1.2.3.4"}

اگر هیچ هدری IP ندهد، جواب `{"error": "no ip"}` با کد ۴۰۰ است.
هیچ چیزی لاگ یا ذخیره نمی‌شود — IP فقط در جواب برگردانده می‌شود تا
اپ آن را به `check_registration` بدهد. تایید JWT روی حالت پیش‌فرض
(روشن) می‌ماند؛ اپ کلید anon را مثل بقیه تماس‌های سوپابیس می‌فرستد.

نصب کردن (یک بار، در داشبورد سوپابیس)
---------------------------------------
۱. داشبورد سوپابیس (پروژه vpn5g) → بخش Edge Functions
۲. گزینه Create a new function (یا Deploy a new function) را بزن و
   اسم تابع را دقیقاً این بگذار: get-client-ip
۳. محتوای فایل index.ts (همین پوشه) را کامل کپی کن و به‌جای کد
   پیش‌فرض تابع بچسبان
۴. Deploy را بزن و صبر کن تا وضعیت تابع Active شود

ترتیب مهم است: این تابع را حتماً قبل از اینکه کاربرها به نسخه ۱.۱.۱۰
آپدیت کنند نصب کن. تا وقتی تابع نصب نشده باشد، ثبت‌نام در ۱.۱.۱۰
با خطای شبکه رد می‌شود (تابع ۴۰۴ می‌دهد و اپ برای امنیت ثبت‌نام را
انجام نمی‌دهد).

تست کردن
---------
بعد از Deploy، این دستور را در ترمینال بزن (به‌جای <ANON_KEY> کلید
anon پروژه را بگذار — کلید واقعی را هیچ‌وقت در چت نفرست):

    curl -i "https://atvcpfnnmwguhjvhbbfj.supabase.co/functions/v1/get-client-ip" \
      -H "apikey: <ANON_KEY>" \
      -H "Authorization: Bearer <ANON_KEY>"

جواب درست:

    HTTP/2 200
    {"ip":"..."}

اگر ۴۰۴ گرفتی یعنی تابع هنوز Deploy نشده یا اسمش دقیقاً
get-client-ip نیست. اگر ۴۰۱ گرفتی یعنی کلید anon درست نیست.
